# ここで寝たらただのサラリーマン

ブラウザだけで遊べる、Vampire Survivors風の見下ろし型シューティングゲームです。
「敵」の正体は次々に舞い込む**仕事**（問い合わせ対応・障害対応・インシデント対応…）で、それを弾で片付けながら、脳疲労・SAN値（精神力）・寿命（健康）をやりくりし、月末まで生き延びる（＝会社員人生を全うする）ことを目指します。

ビルドツールや外部ライブラリは一切使っていません。`index.html` をブラウザで開くだけで遊べます。

## 遊び方（操作方法）

### PC（キーボード・マウス）
| 操作 | 内容 |
|---|---|
| W / A / S / D | 自分の移動 |
| マウス移動 | 照準（自分は常にマウスカーソルの方向を向く） |
| マウス左クリック（押しっぱなし） | 攻撃（手動） |
| F | 自動攻撃のON/OFF切り替え |
| P | 一時停止 / 再開 |
| 数字キー・Y/N など | 各種選択画面での選択（画面の案内に従ってください） |

### スマートフォン（タッチ）
- 画面の**左下の仮想スティック**：移動
- 画面の**右下の仮想スティック**：倒す方向にドラッグすると自分の向きが変わり、触れている間は自動的に攻撃します
- 画面右上のボタン：自動/手動の切り替え、一時停止
- メニュー画面の選択肢は、ボタンをタップするだけでOKです
- 画面を縦向き（ポートレート）にすると「横向きにしてください」という案内が表示されます。横向き（ランドスケープ）で遊んでください

## ゲームの始め方

1. `index.html` をブラウザで開く
2. **自分のアイコン**を6種類の中から選ぶ
3. **同僚のアイコン**を6種類の中から選ぶ、または「同僚なし」を選ぶ
4. スタート画面で「通常開始」か「3倍加速モード」を選んでゲーム開始（3倍速は時間の流れが速くなるモードです）

---

## 画面の見方（HUD）

- 左上：選択したアイコンを仮の顔イラストとして表示する**自分プロフィール区画**
- その右：同じ高さに並ぶ**同僚プロフィール区画**（同僚なし・離脱時も状態を表示）
- 各プロフィールのイラスト下：それぞれの**SAN・寿命・脳疲労**。自分側にはScore・Rank・Skill Lvl / EXPも表示
- プロフィール区画の下：**週ノルマ**の進捗と攻撃モード
- 右上：**DAY数・日付・時刻・曜日**（土日祝日は黄色で表示）
- 画面中央上部：ゲーム内のできごとを知らせる一時メッセージ

## ゲームの流れ

```
アイコン選択 → スタート画面 → 平日を働く（1日=9:00〜18:00） → DAY表示でクリック/タップ待ち → 翌日へ
                                        │
                                        └─ 金曜日（祝日ならその前日）の終業時に「週間ノルマ」を判定
                                                │
                                    ノルマ達成 ─┤─ ノルマ未達成
                                        │              │
                              労いメッセージ      「休日出勤しますか？」(Y/N)
                                        │          ┌─────┴─────┐
                                        │        出勤する      休む（評価がさらに下がる）
                                        │          │              │
                                 「休日の過ごし方」3択（同僚と遊ぶ／休息／勉強）
                                        │
                                週末ランダムイベント発生（SAN増減・スキル習得/忘却・変化なし、いずれか）
                                        │
                                クリック/タップで次の週（月曜日）へ
```

これを月の末日を迎えるまで繰り返します。月末まで到達すると「ゲームクリア」＝エンディングとなります（詳しくは[エンディング](#エンディング)を参照）。

### 仕事（敵）を片付ける
- 敵の正体は「問い合わせ対応」「障害対応」「インシデント対応」など、弱い順に10種類の仕事です。ランクが上がるほど、強い（＝厄介な）仕事も出現するようになります。
- 敵は**最大3体（1ウェーブ）**まで同時に出現し、**全員片付けるまで次のウェーブは出てきません**。
- 敵にはそれぞれ**納期**（残り時間）があり、時間切れになると「爆発」してSANにダメージを受けます（ダメージ量は接触時の約1.5倍です）。
- 敵を倒すと**Score**・**経験値（EXP）**・**週間ノルマの進捗**が増えます。

## 各種システムの詳細

### 脳疲労
- 攻撃するたびに増え、待機中（移動していない時）に一番早く回復します。
- 最大値に達すると一時的に操作不能（居眠り状態）になり、SANダメージに加えて寿命も2～3減ります。
- チョコレート（🍫、画面にランダム出現）を取ると回復します。

### SAN値（精神力）
- 敵との接触、納期切れの爆発、脳疲労の限界到達、週間ノルマ未達成時のペナルティ、休日イベントの一部などでダメージを受けます。
- **0になるとゲームオーバー**（バッドエンド：発狂パターン）。

### 寿命（健康）
- SANとは別の、じわじわとしか減らない・じわじわとしか自覚できないパラメータです。
  - SANダメージを受けるたびに、その**15%ぶん**が寿命にも波及します
  - 脳疲労が80%を超えた状態、またはSANが20%を下回った状態が**4秒以上続く**と、その後は1秒ごとに少しずつ削れていきます
- **0になるとゲームオーバー**（バッドエンド：力尽きるパターン）。SANを回復させても、蓄積した消耗（寿命）は元に戻らないのがポイントです。

### 週間ノルマ・昇進（ランク）
- 月〜金（祝日を考慮）の1週間の中で、**撃破数**または**獲得スコア**のどちらかがノルマ値に達すればクリアです。
- ノルマを早めに達成すると、その週の残りは易しい仕事しか出てこなくなります。
- 昇進（ランク1→10）の判定は**週末（および月末）にのみ**行われ、スコアが複数ランク分の条件を満たしていれば**飛び級**もあり得ます。最終ランク（10）への到達条件は特に厳しく設定されています。

### 敵の強さの変化
- 敵のHP（残り工数）は従来の約3倍です。HPと、接触・爆発によるSANダメージ（攻撃力）は、**ゲーム内の経過日数に応じてどんどん強くなっていきます**（1日ごとに約6%）。同じ種類の仕事でも、後半になるほど手強くなります。
- 1日の中でも、終業時刻が近づくほど敵の動きが速くなります。

### スキルレベルと経験値
- 敵を倒すと経験値（EXP）が入り、貯まるとスキルレベルが上がります。
- レベルアップに必要な経験値は、**レベルが上がるほど増えていきます**（後半は上がりにくくなる調整済み）。
- スキルレベルが5上がるごとに、下記の**特殊スキル**を1つ選んで習得（またはレベルアップ）できます。

## 同僚について

- ゲーム開始時にアイコンを選ぶと、自分に付き従う仲間が登場します（「同僚なし」も選択可）。
- 基本は自分に追従しますが、時々ランダムにふらふらと徘徊し、近くの敵に自動で攻撃します。撃破した分はプレイヤーのScore・週間ノルマ・EXPにそのまま加算されます。
- 自分と同僚の弾は互いにも当たり、誤射されるとSANと寿命が減ります。同僚弾を自分が受けた場合は、SANと寿命がそれぞれ2減り、画面揺れと赤いフラッシュが発生します。「チームワーク」を習得すると誤射を無効化できます。
- 同僚との関係性は0（最悪）～100（良好）の内部パラメータとして管理され、画面には表示されません。初期値は50です。自分の弾を当てるたびに悪化し、一定以下になると同僚がときどき自分を狙います。休日に「同僚と遊ぶ」を選ぶと関係性が改善します。
- 関係性が50以上なら、同僚は発射時点の自分へ当たる弾道を避けます。ただし、発射後に自分から弾道へ入った場合は被弾します。
- 関係性の数値は表示されませんが、悪化して0に近づくほど、同僚の顔アイコンを囲む円形フレームが連続的に赤くなります。プロフィール区画の背景は半透明で、背後の敵も確認できます。
- 自分と同じように**脳疲労・SAN・寿命**を持ち、敵との接触でSANが減り、悪い状態が続くと寿命も減ります。
- **賢さ（intelligence）**と**性格＝向こう見ずさ（recklessness）**という2つの特性を持ち、ゲーム開始時にランダムに決まります。
  - 賢く・慎重な性格ほど、疲れているときに無駄撃ちを避け、狙いも正確になります。
  - 向こう見ずな性格だと、疲れていても構わず撃ち続け、狙いも雑になりがちです。
  - これらの特性は、自分が持つ特殊スキル（学習力・傾聴力・自己中心性・注意力散漫など）によっても実効的に変化します。
- **SANまたは寿命が0になると、同僚は力尽きて以後二度と登場しません**。同時にプレイヤー自身もSANダメージを受けます。
- 同僚を一度でも失うと、**トゥルーエンドの条件を満たせなくなります**。最後まで大切にケアしましょう。

## エンディング

月末（クリア）またはゲームオーバー時に、5種類のいずれかのエンディング画面（仮の絵文字＋説明文＋END表示）が表示されます。

| エンディング | 到達条件 |
|---|---|
| **トゥルーエンド** 🌟 | 最終ランク（Rank10）到達 ＋ 週末の特殊イベント（後述）を毎回正しく選択 ＋ 同僚を一度も失っていない |
| **ノーマルエンド** 🏁 | 月末に到達したが、トゥルーエンドの条件を満たせなかった場合 |
| **バッドエンド（発狂）** 🌀 | SAN値が0になった場合 |
| **バッドエンド（力尽きる）** ⚰️ | 寿命が0になった場合 |
| **バッドエンド（関係性）** 💔 | 同僚からの被弾でSANまたは寿命が0になった場合 |

エンディング画面には「もう一度プレイする」（最初からやり直し）・「終了する」（タブを閉じようと試みます）のボタンがあります。

## 現状の制約・仮実装について

- **グラフィックはすべて絵文字のプレースホルダーです**。自分・同僚・敵・背景装飾など、正式なイラスト素材はまだ用意していません（`images/` フォルダは空です）。
- **サウンド・音楽は未実装です**（`sounds/` フォルダは空です）。
- **週末の「特殊イベント」（トゥルーエンド条件に関わる、正誤のある選択イベント）はまだ内容が実装されていません**。プログラム上のフック（`recordSpecialEventChoiceResult`、`adjustPartnerTraits`）だけ用意してあります。
- スコアをサーバーへ送信する処理（`sendScore`）は `http://localhost:8080/score` 宛て決め打ちです。受け取るサーバーが無い場合はコンソールにエラーが出るだけで、ゲーム進行には影響しません。
- 数値バランス（ノルマ・ランク条件・成長率など）は、遊びながらの調整を重ねた初期チューニングであり、今後も見直しが必要になる可能性があります。

## ファイル構成

```
index.html   … ページの骨組み、アイコン選択・タッチ操作UI・回転案内オーバーレイ
style.css    … レイアウト、レスポンシブ対応、仮想スティックの見た目
main.js      … ゲームロジック全体（1ファイルにまとまっています）
images/      … 将来、正式なグラフィック素材を置くための空フォルダ
sounds/      … 将来、効果音・BGMを置くための空フォルダ
```

`main.js` は上から順に、敵の生成・弾とスコア・脳疲労/SAN/寿命システム・日付とカレンダー・週次ノルマ・特殊スキル・入力処理（キーボード/マウス/タッチ）・同僚・描画（`draw()`関数）という構成になっています。コメントで区切られているので、`// =====` を目印に探すと見つけやすいです。

## 今後の改善の方向性

- **週末の特殊イベントの本実装**：内容（設問・正誤・演出）を決めて、トゥルーエンド条件と同僚の性格変化に接続する
- **正式なグラフィック・サウンド素材への差し替え**：絵文字プレースホルダーからイラスト・効果音・BGMへ
- **数値バランスの継続調整**：週間ノルマ、ランク昇進条件、敵の成長速度などをプレイテストしながら微調整
- **セーブ／ロード機能**：ブラウザを閉じても続きから再開できるようにする
- **実績・統計・エンディング回収状況の記録**：達成したエンディングの種類などをlocalStorage等に保存
- **難易度選択**：初心者向けの易しいモードなど、遊ぶ人に応じた難易度の選択肢
- **チュートリアル・初回操作ガイドの強化**：特にスマートフォン初見のユーザー向け
- **スコア送信先の整理**：`sendScore`の送信先をランキングサーバー等、実際の用途に合わせて実装
- **アクセシビリティ対応**：色覚特性への配慮、文字サイズ調整など
