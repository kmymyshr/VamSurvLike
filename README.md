# ここで寝たらただのサラリーマン（Workin' FunDead）

ブラウザだけで遊べる、Vampire Survivors風の見下ろし型シューティングゲームです。
「敵」の正体は次々に舞い込む**仕事**（問い合わせ対応・障害対応・インシデント対応…）で、それを弾で片付けながら、脳疲労・SAN値（精神力）・寿命（健康）をやりくりし、月末まで生き延びる（＝会社員人生を全うする）ことを目指します。

追い詰められて限界を超えると、窓の外から**名状しがたい何か**が現れることもあります。

ビルドツールや外部ライブラリは一切使っていません。`index.html` をブラウザで開くだけで遊べます。

## 遊び方（操作方法）

### PC（キーボード・マウス）
| 操作 | 内容 |
|---|---|
| W / A / S / D | 自分の移動 |
| マウス移動 | 照準（自分は常にマウスカーソルの方向を向く） |
| マウス左クリック（押しっぱなし） | 攻撃（手動） |
| Space | パリィ（自分・同僚に向かってくる弾を、周囲まとめてはじき返す） |
| F | 自動攻撃のON/OFF切り替え |
| P | 一時停止 / 再開 |
| 数字キー・Y/N など | 各種選択画面での選択（画面の案内に従ってください） |

### スマートフォン（タッチ）
- 画面左下の**十字（D-pad）ボタン**：上下左右への移動
- 画面右下の**連射ボタン**：押している間、狙いを自動で近くの敵に定めながら攻撃（「スマホ用 自動照準」設定で挙動を切替可能）
- 連射ボタンの真上の**パリィボタン**：向かってくる弾をはじき返す
- 画面右上のボタン：自動/手動の切り替え、一時停止
- メニュー画面の選択肢は、ボタンをタップするだけでOKです
- 画面を縦向き（ポートレート）にすると「横向きにしてください」という案内が表示されます。横向き（ランドスケープ）で遊んでください

## ゲームの始め方

1. `index.html` をブラウザで開く
2. スタート画面で「通常開始」か「3倍加速モード」を選ぶ（3倍速は時間の流れが速くなるモードです）
3. **自機の性別**（男性／女性）を選ぶ
4. **同僚のアイコン**を12種類の中から選ぶ、または「同僚なし」を選ぶ
5. ひとことメッセージのあと、ゲームが始まります

一度クリアかゲームオーバーを経験すると、タイトル画面に「夢の記憶ポイントで強化」「夢と同じ設定で進める」「エンディングリスト」のボタンが増えます（詳しくは後述）。

## 画面の見方（HUD）

- 左上：選択したアイコンとパラメータをまとめた、コンパクトな**自分プロフィール区画**
- その右：同じ高さに並ぶ**同僚プロフィール区画**（同僚なし・離脱時も状態を表示）
- 各プロフィールのイラスト下：それぞれの**SAN・寿命・脳疲労**。自分側にはScore・Rank・Skill Lvl / EXPも表示
- プロフィール区画の下：**週ノルマ**の進捗と攻撃モード
- 右上：**DAY数・日付・時刻・曜日**（土日祝日は黄色で表示）
- 画面中央上部：ゲーム内のできごとを知らせる一時メッセージ
- クイズ正解・スキルレベル上昇時：ゲームが一時停止し、確認通知をクリック／タップすると再開（昇進はゲームを止めず、その場でメッセージ表示のみ）
- 寿命が残り少ないほど、画面の端からひび割れ・暗転が進行する演出が入ります
- 自分・同僚のSANがいずれも20を切ると、画面全体が暗く赤みがかった不穏な空気になります（ラスボス出現の前兆）
- **一時停止画面（Pキー）**：自分・同僚の基本パラメータ（SAN・寿命・脳疲労・Score・Rank・関係性など）に加え、現在かかっているバフ・デバフ（無敵時間・stun・栄養ドリンク/コーヒー効果・固定敵由来の状態異常など）、習得済みの特殊スキル・役職スキルの一覧をまとめて確認できます

## ゲームの流れ

```
性別・同僚選択 → スタート画面 → 平日を働く（1日=9:00〜18:00） → DAY表示でクリック/タップ待ち → 翌日へ
                                        │
                                        └─ 金曜日（祝日ならその前日）の終業時に「週間ノルマ」を判定
                                                │
                                    ノルマ達成 ─┤─ ノルマ未達成
                                        │              │
                              労いメッセージ      「休日出勤しますか？」(Y/N)
                                        │          ┌─────┴─────┐
                                        │        出勤する      休む（評価がさらに下がる）
                                        │          │              │
                                 「休日の過ごし方」3択（同僚と遊ぶ／休息／勉強）
                                        │
                                週末ランダムイベント発生（SAN増減・スキル習得/忘却・変化なし、いずれか）
                                        │
                                クリック/タップで次の週（月曜日）へ
```

これを月の末日を迎えるまで繰り返します。月末まで到達すると「ゲームクリア」＝エンディングとなります（詳しくは[エンディング](#エンディング)を参照）。DAY7ごとの18時には「巨大案件」（中ボス）が、SANが自分・同僚とも20を切るとラスボスが割り込んでくることがあります。

### 仕事（敵）を片付ける
- 敵の正体は「問い合わせ対応」「障害対応」「インシデント対応」など、弱い順に10種類の仕事です。ランクが上がるほど、強い（＝厄介な）仕事も出現するようになります。
- 敵は**最大3体（1ウェーブ）**まで同時に出現し、**全員片付けるまで次のウェーブは出てきません**。
- 敵にはそれぞれ**納期**（残り時間）があり、時間切れになると「爆発」してSANにダメージを受けます（ダメージ量は接触時の約1.5倍です）。
- 敵を倒すと**Score**・**経験値（EXP）**・**週間ノルマの進捗**が増えます。

## 各種システムの詳細

### 時間帯ライティング
- 朝は薄い暖色を重ねて明るく表示し、夕方へ近づくほど画面全体が連続的に暗くなります。
- 暗い時間帯でも、自分と同僚の周囲は円形にぼんやり照らされます。離れた敵ほど見つけにくくなります。

### 定時報告
- **3日ごとの16時**に、画面内のランダムな位置へ固定ターゲット「定時報告」（📊）が出現します。
- 通常の仕事より大幅にHPが高く、その場から移動しません。同僚も通常の仕事より優先して攻撃します。撃破するとScoreを獲得します。
- 接触ダメージはありませんが、固定された障害物として扱われ、自分も同僚も通り抜けられません。
- 18時までに倒せないと消滅し、現在の**Scoreが半分**になります。

### 昼食
- 11時になると昼食が近いことを知らせる予告が表示されます。
- 毎日12時に、4個の食べ物が約0.55秒間隔で一つずつランダムな位置へ出現します。
- 15時になると残った食べ物が点滅し始め、約1.8秒後に消滅して未取得数の判定が行われます。
- 一品取るごとにSAN +2、寿命 +0.5、脳疲労 -3の小回復があります。
- 出現順どおりに全品取ると、追加でSAN +10、寿命 +4、脳疲労 -15の昼食ボーナスを獲得します。順番を一度でも間違えると追加ボーナスは半減します。
- 終業までの取得数が半分以下（2個以下）なら「ちゃんと食事を取らなかった」と判定され、寿命が5減ります。

### クイズ
- 平日の10時・15時に各20%で抽選され、**週2回まで**ITまたはコミュニケーションに関する三択クイズが発生します（平均して週2回程度）。
- 設問は画面上部に表示され、マップに固定出現する1️⃣・2️⃣・3️⃣のどれかを取ると回答になります。
- 正解すると、問題分野に対応する非表示の内部能力値が1上昇します。不正解時の能力低下はありません。
- 未回答のクイズは終業時に消滅します。

### 脳疲労・コーヒー・栄養ドリンク
- 攻撃するたびに増え、待機中（移動していない時）に一番早く回復します。最大値に達すると一時的に操作不能（居眠り状態）になり、SANダメージに加えて寿命も2〜3減ります。
- チョコレート（🍫、画面にランダム出現）を取ると回復します。
- 画面端に固定されたコーヒーメーカー・冷蔵庫から、**コーヒー**（時間経過では消えない・stunを1杯につき1回回避できる）と**栄養ドリンク**（効果は強いが切れると反動あり）を随時補充できます。同僚もこれらを飲みます。
- コーヒー・栄養ドリンクを飲みすぎたり、夕方以降に飲んだりすると、回復量減少などのペナルティが入ります。

### 「ファイヤーウォール」（レアアイテム）
- 低確率で出現する希少アイテムで、取得すると誤射・接触ダメージを一定回数無効化するバリアが張られます。

### SAN値（精神力）
- 敵との接触、納期切れの爆発、脳疲労の限界到達、週間ノルマ未達成時のペナルティ、休日イベントの一部などでダメージを受けます。
- **0になるとゲームオーバー**（バッドエンド：発狂パターン）。

### 寿命（健康）
- SANとは別の、じわじわとしか減らない・じわじわとしか自覚できないパラメータです。
  - SANダメージを受けるたびに、その**15%ぶん**が寿命にも波及します
  - 脳疲労が80%を超えた状態、またはSANが20%を下回った状態が**4秒以上続く**と、その後は1秒ごとに少しずつ削れていきます
- **0になるとゲームオーバー**（バッドエンド：力尽きるパターン）。SANを回復させても、蓄積した消耗（寿命）は元に戻らないのがポイントです。

### 週間ノルマ
- 月〜金（祝日を考慮）の1週間の中で、**撃破数**または**獲得スコア**のどちらかがノルマ値に達すればクリアです。
- ノルマを早めに達成すると、その週の残りは易しい仕事しか出てこなくなります。

### ランク・役職スキル
- 「昇進」を選ぶ場面はなく、**Scoreに応じてランク（役職名）が自動的・段階的に上がっていきます**（週末を待たず、その場で判定されます）。スコアが複数ランク分の条件を満たしていれば飛び級もあり得ます。最終ランク（Rank7）への到達条件は特に厳しく設定されています。
- ランクが上がると、そのランクに紐づく**役職スキル**（身につけた開発手法）を自動的にすべて習得します。選択の余地はなく、恒久的な効果として積み重なっていきます。

| ランク | 役職名 | 習得する開発手法（効果） |
|---|---|---|
| 1 | 未経験 / 新人 | 構造化プログラミング（弾のダメージ+10%） |
| 2 | PG | オブジェクト指向（EXP獲得+20%） |
| 3 | SE | IDE（発射間隔-15%）・デバッガ（被SANダメージ-15%）・バージョン管理（誤射ダメージ-20%） |
| 4 | 上級SE / サブリーダー | フレームワーク（移動速度+10%）・ライブラリ（弾のダメージ+15%）・O/Rマッパー（獲得Score+15%） |
| 5 | PL / プロジェクトリーダー | 自動テスト（被SANダメージ-20%）・CI/CD（発射間隔-20%）・ビルド自動化（射撃による脳疲労-20%） |
| 6 | PM / プロジェクトマネージャー | アジャイル開発（敵の納期+20%、「巨大案件」はどのフェーズに当てても今の番号への命中として扱われる）・DevOps（同僚の攻撃力+15%）・クラウド（最大SAN・最大寿命+10）・コンテナ（移動速度+15%） |
| 7 | 部長 / 事業責任者 / CTO | AIコード補完（発射間隔-30%）・生成AI（弾のダメージ+30%）・AIエージェント（1日10回まで、同僚への誤射を最寄りの敵への即死攻撃に変換） |

これらの効果はすべて重ね掛けされるため、最終ランクに到達する頃には素の状態から大きく強化されます。

### 敵の強さの変化
- 敵のHP（残り工数）は従来の約3倍です。HPと、接触・爆発によるSANダメージ（攻撃力）は、**ゲーム内の経過日数に応じてどんどん強くなっていきます**（1日ごとに約6%）。同じ種類の仕事でも、後半になるほど手強くなります。
- 1日の中でも、終業時刻が近づくほど敵の動きが速くなります。

### スキルレベルと経験値
- 敵を倒すと経験値（EXP）が入り、貯まるとスキルレベルが上がります。
- レベルアップに必要な経験値は、**レベルが上がるほど増えていきます**（後半は上がりにくくなる調整済み）。
- スキルレベルが5上がるごとに、下記の**特殊スキル**を1つ選んで習得（またはレベルアップ）できます。

### フルオートモード
- 移動・攻撃・回避をすべて自動で行うモードです。優先度は「同僚やボスの弾を避ける」＞「敵を避ける」＞「昼食・チョコ・ファイヤーウォール・クイズを拾いに行く」＞「同僚との距離を保つ」の順で判断します。

## 同僚について（パリィ・関係性・再会シーン）

- ゲーム開始時にアイコンを選ぶと、自分に付き従う仲間が登場します（「同僚なし」も選択可）。
- 自分との距離を広めに取り、追従はゆっくり行います。多くの時間は画面内のランダムな位置へ自発的に徘徊し、近くの敵に自動で攻撃します。撃破した分はプレイヤーのScore・週間ノルマ・EXPにそのまま加算されます。
- 自分と同僚の弾は互いにも当たり、誤射されるとSANと寿命が減ります。「チームワーク」を習得すると被害を軽減できます。
- 同僚との関係性は0（最悪）～100（良好）の内部パラメータとして管理され、初期値は50です。自分の弾を当てるたびに悪化し、一定以下になると同僚がときどき自分を狙います。休日に「同僚と遊ぶ」を選ぶと関係性が改善します。悪化して0に近づくほど、同僚アイコンの円形フレームが連続的に赤くなります。
- 自分と同じように**脳疲労・SAN・寿命**を持ち、敵との接触でSANが減り、悪い状態が続くと寿命も減ります。**賢さ**と**向こう見ずさ**という2つの特性を持ち、休日イベントや自分の特殊スキルによって変化します。
- **SANまたは寿命が0になると、同僚は力尽きて以後二度と登場しません**。同僚を一度でも失うと、トゥルーエンドの条件を満たせなくなります。

### パリィ（弾のはじき返し）
- Space（スマホはパリィボタン）で、自分・同僚に向かってくる弾を周囲まとめてはじき返せます。複数同時パリィも可能です。
- 同僚も自動で、被弾しそうな時に一定確率（初期30%、夢の記憶ポイントで強化可能）でパリィし、「パリィ！」「効かないよ！」などの吹き出しを表示します。
- パリィで反射した弾は速度が1.5倍になり、発射元（ラスボス・中ボスの発射口）に向かって飛んでいきます。

### 再会シーン
- 前回プレイと同じ自機の性別・同僚を選んでゲームを始めると、前回の関係性・最期の状況に応じた再会シーン（セリフ・アイコンの色味変化）が挿入されます。

## ラスボス・中ボスについて

### ラスボス
- 自分・同僚のSANがいずれも20を切ると、窓の外から名状しがたい巨大な存在が現れます。出現中は時間が止まり、通常の敵は現れず、ラスボスとだけ戦うことになります。
- 本体には複数の発射口があり、そこから自分・同僚どちらかを狙って弾が飛んできます。本体そのものへの接触でもダメージを受けます。
- 発射口はそれぞれ耐久力を持ち、通常攻撃・パリィどちらでも破壊できます。5個→7個→10個と段階的に発射口が増え、最終段階の発射口は本体上をランダムに動き回ります。
- すべての発射口を破壊しきると、本体が振動しながらゆっくり後退・フェードアウトして消え、背景が元のオフィスに戻ったあと画面が白く（または、同僚を失っている場合は黒く）フェードし、エンディングへ至ります。
- 中ボス（「巨大案件」）が出現中は、ラスボスは発生しません。

### 中ボス（「巨大案件」）
- DAY7ごとの18時に、窓の上を動き回る「巨大案件」が出現します。出現すると自動的に残業モードに入り、24時までに倒せなければ24時で時刻が停止し、倒すまで継続します（時刻表示には鉛筆で取り消し線を引いたようなエフェクトが重なります）。
- 発射口は「フェーズ」と呼ばれ、システム開発の工程（①企画・②要件定義・③基本設計・④詳細設計・⑤開発・⑥テスト・⑦リリース・運用保守）になぞらえた7つを持ちます。それぞれ本体の上をゆっくりランダムに動き回りますが、**番号順にしか破壊できません**（現在の番号以外は鍵がかかったように無効化されています）。
- 今対応中のフェーズの番号・名称と、その工程の内容（現実の説明文）が画面にフェードイン表示され、破壊するまで表示され続けます。破壊すると「◯. ○○完了！」と表示されてフェードアウトし、次のフェーズへ進みます。破壊した発射口はその場で消滅します。
- 全7フェーズを破壊し終えると、動作はラスボスとほぼ同様（振動・フェードアウトして撃破）です。撃破すると通常の敵より多めのScoreが手に入ります。
- フェーズ1つあたりの耐久力はDAYが進むごとに上がります（DAY7を基準に、DAY14で2倍、DAY21で3倍、DAY28以降で5倍）。
- 倒した翌日は通常どおり、残業なしで始まります。

## 固定敵（IT用語モチーフ）

- 平日13時に判定され、**60%の確率（週3回程度）**で1体だけ出現する、移動しない特殊な敵です。名称はIT・セキュリティ用語から取られ、現実の攻撃内容にちなんだ攻撃パターン・被弾時の悪影響を持ちます。
- 定時報告・ラスボス・中ボスとは同時に出現しません。倒せないまま終業を迎えると、ペナルティなしで見逃す形になります。
- 通常の弾・パリィで撃破可能です（一部はパリィで打ち返した弾を本体に向けて反射させられます）。撃破するとScoreを獲得し、その用語の**現実の説明文**が画面上部にフェードイン→3秒表示→フェードアウトします。
- 攻撃パターンは大きく5種類：**弾を発射する**（DoS・ブルートフォース・ゼロデイなど）、**弾を介さず直接効果を及ぼす**（SQLインジェクション・ランサムウェアなど）、**偽アイテムの罠を置く**（フィッシング・DNSスプーフィングなど）、**自機に見せかけて同僚を誤射させる**（なりすまし・中間者攻撃）、**雑魚を追加召喚する**（ボットネット）。
- 被弾時の効果例：発射間隔延長、移動速度低下、操作反転、Score浸食、一時的な攻撃不能、脳疲労急増、疲労回復停止＋継続SANダメージ、視界不良、移動乗っ取り、同僚の一時的な行動停止、関係性ダメージ、一定確率で回避（キーロガー）、撃破後の遅延不意打ち（バックドア設置）など。

| 攻撃名 | 攻撃パターン | 主な被弾効果 |
|---|---|---|
| DoS攻撃 | 3連続の弾を発射 | 発射間隔が一時的に延びる |
| DDoS攻撃 | 5連続の弾＋雑魚を召喚 | 移動速度が低下する |
| XSS | 単発の弾 | 操作（移動キー）が一時的に反転する |
| SQLインジェクション | 弾を撃たず、継続的にScoreを浸食 | Scoreが少しずつ減り続ける |
| CSRF | 単発の弾 | 一時的に攻撃できなくなる |
| フィッシング | 偽の回復アイテムの罠を設置 | 脳疲労が急増する |
| マルウェア感染 | 単発の弾 | 疲労回復停止＋継続SANダメージ（感染） |
| ランサムウェア | 弾を撃たず、周期的にScoreを要求 | Scoreがまとまって減る |
| ブルートフォース攻撃 | 高頻度の単発弾 | （継続的な被弾ダメージ） |
| 辞書攻撃 | パターン化した弾道の単発弾 | （継続的な被弾ダメージ） |
| パスワードリスト攻撃 | 自機の移動を先読みした単発弾 | （継続的な被弾ダメージ） |
| 中間者攻撃 | 自機に見せかけて同僚を狙う | 同僚が誤射と勘違いし、SAN・関係性が低下 |
| 盗聴・スニッフィング | 近づくと発動（弾なし） | 画面が暗くぼやけ、視界不良になる |
| DNSスプーフィング | 偽の位置に罠を設置 | 見た目と異なる位置で発動し、SANダメージ |
| ゼロデイ攻撃 | 予兆なしの強力な弾 | 被ダメージが大きい |
| 権限昇格 | 時間経過で弾数・頻度が強化される | 長引くほど被ダメージが増す |
| バックドア設置 | 低頻度の単発弾 | 撃破後もしばらく不意打ちが飛んでくる |
| サプライチェーン攻撃 | 通常アイテムに擬態した罠 | 感染（疲労回復停止＋継続SANダメージ） |
| 標的型攻撃 | 自機だけを執拗に狙う弾 | 発射間隔が延びる |
| ソーシャルエンジニアリング | 偽の選択肢の罠 | 同僚との関係性が低下する |
| なりすまし | 自機に見せかけて同僚を狙う | 同僚が誤射と勘違いし、SAN・関係性が低下 |
| メールスプーフィング | 偽の通知の罠 | SANダメージ |
| クリックジャッキング | 偽の操作ボタンの罠 | 一時的に攻撃できなくなる |
| ディレクトリトラバーサル | 画面の隅から不意に出現する弾 | （不意打ちによる被弾） |
| リモートコード実行 | 単発の弾 | 一時的に移動が乗っ取られる |
| セッションハイジャック | 単発の弾 | 同僚が一時的に行動を止める |
| キーロガー | 単発の弾（35%の確率で自ら回避する） | （回避されると攻撃が通らない） |
| ボットネット | 弾は撃たず、雑魚を継続的に召喚 | （周囲の雑魚が増える） |
| 水飲み場攻撃 | 食事アイテムに擬態した罠 | 感染（疲労回復停止＋継続SANダメージ） |
| 内部不正 | 弾を撃たず、周期的に発動 | 同僚が一時的に行動を止める |

## 夢の記憶ポイント（周回強化）

- ゲームオーバー・クリア時に獲得したScoreの一部が「夢の記憶ポイント」に変換され、`localStorage` に永続的に保存されます。
- タイトル画面の「夢の記憶ポイントで強化」から、初期スキルレベル・初期SAN／寿命上限・初期脳疲労上限・初期スコア・初期攻撃力・初期移動速度・初期バリア回数・同僚との初期関係性・週間ノルマ緩和・同僚のオートパリィ確率などを、ポイントを消費して強化できます。
- 「思い直す」ボタンで、費やしたポイントを全額払い戻し、レベルを0に戻して振り分け直せます。
- 一部の強化は1レベルのみ購入可能な特殊効果です（例：`DreamCatcher`＝SAN上限を25固定にしてラスボスに遭遇しやすくする、`祈る`／`根性`＝SANまたは寿命が0になる一撃を耐えて自動回復、`無敵（テスト用）`＝SAN・寿命が0にならず脳疲労も常に0、攻撃力10倍という検証用の特殊スキル）。
- タイトル画面の「エンディングリスト」ボタンから、これまでに到達したエンディングの一覧を確認できます（未到達のものは内容が伏せられます）。

## エンディング

月末（クリア）・ゲームオーバー・ラスボス撃破時に、いずれかのエンディングへ至ります。

| エンディング | 到達条件 |
|---|---|
| **TRUE END** 🌟 | 最終ランク（Rank7）到達 ＋ 週末の特殊イベント（後述）を毎回正しく選択 ＋ 同僚を一度も失っていない |
| **NORMAL END** 🏁 | 月末に到達したが、TRUE ENDの条件を満たせなかった場合 |
| **BAD END（心）** 🌀 | SAN値が0になった場合 |
| **BAD END（寿命）** ⚰️ | 寿命が0になった場合 |
| **BAD END（同僚）** 💔 | 同僚の誤射でとどめを刺された場合 |
| **目覚めエンド** 👁️ | ラスボスを撃破し、同僚が生存している状態で終えた場合 |
| **もう一つの目覚めエンド** 🖤 | ラスボスを撃破したが、同僚を失っている場合 |

エンディング画面には「・・・という夢をみました」（最初からやり直し。夢の記憶ポイントは引き継ぎ）・「終了する」（タブを閉じようと試みます）のボタンがあります。到達済みのエンディングは、タイトル画面の「エンディングリスト」からいつでも確認できます。

## 現状の制約・仮実装について

- 自機・同僚・背景（朝〜夜）は画像素材が用意済みですが、**中ボス「巨大案件」の見た目はまだ矩形のプレースホルダー**、**固定敵（IT用語モチーフ）は絵文字アイコンのみ**です（正式な画像は追加予定）。
- **サウンド・音楽は未実装です**（`sounds/` フォルダは空です）。
- **週末の「特殊イベント」（TRUE ENDの条件に関わる、正誤のある選択イベント）はまだ内容が実装されていません**。プログラム上のフック（`recordSpecialEventChoiceResult`、`adjustPartnerTraits`）だけ用意してあります。
- スコアをサーバーへ送信する処理（`sendScore`）は `http://localhost:8080/score` 宛て決め打ちです。受け取るサーバーが無い場合はコンソールにエラーが出るだけで、ゲーム進行には影響しません。
- 「夢の記憶ポイント」の`無敵（テスト用）`スキルは検証用に用意した仮実装で、将来的に整理・削除される可能性があります。
- 数値バランス（ノルマ・ランク条件・成長率など）は、遊びながらの調整を重ねた初期チューニングであり、今後も見直しが必要になる可能性があります。


## 今後の改善の方向性

- **週末の特殊イベントの本実装**：内容（設問・正誤・演出）を決めて、TRUE END条件と同僚の性格変化に接続する
- **中ボス・固定敵専用グラフィックの追加**：現在プレースホルダーの矩形表示・絵文字アイコンを正式なイラストに差し替える
- **サウンド・BGMの追加**：効果音・BGMをまだ実装していない
- **数値バランスの継続調整**：週間ノルマ、ランク昇進条件、敵・ボスの強さなどをプレイテストしながら微調整
- **難易度選択**：初心者向けの易しいモードなど、遊ぶ人に応じた難易度の選択肢
- **チュートリアル・初回操作ガイドの強化**：特にスマートフォン初見のユーザー向け
- **スコア送信先の整理**：`sendScore`の送信先をランキングサーバー等、実際の用途に合わせて実装
- **アクセシビリティ対応**：色覚特性への配慮、文字サイズ調整など
