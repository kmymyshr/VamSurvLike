# ここで寝たらただのサラリーマン（Workin' FunDead）

ブラウザだけで遊べる、古典的な見下ろし型アクション・シューティングゲームです。
「敵」の正体は次々に舞い込む**仕事**（問い合わせ対応・障害対応・インシデント対応…）で、それを弾で片付けながら、脳疲労・SAN値（精神力）・寿命（健康）をやりくりし、月末まで生き延びる（＝会社員人生を全うする）ことを目指します。

追い詰められて限界を超えると、窓の外から**名状しがたい何か**が現れることもあります。その先には、同僚との関係を軸にした「アドベンチャーパート」や、隠された「夢ルート」、そしてこのゲーム事実上のTRUE ENDである「目覚めエンド」が待っています。

ビルドツールや外部ライブラリは一切使っていません。`index.html` をブラウザで開くだけで遊べます。

## 遊び方（操作方法）

### PC（キーボード・マウス）
| 操作 | 内容 |
|---|---|
| W / A / S / D | 自分の移動 |
| マウスポインタ | 向き（自分は常にマウスカーソルの方向を向く） |
| マウス左クリック（アイテムの上） | 発射せず、その場でアイテムだけを取得する |
| 自機本体をクリック＆ドラッグ | 攻撃せず、ドラッグしている間だけマウスカーソルの位置へ自機を移動させる（ドラッグ中はカーソルが自機に重なって方向がぶれやすいため、ドラッグ開始時点の向きを維持する） |
| マウス左クリック（それ以外の場所、押しっぱなし） | 攻撃（手動）。押して離すだけ（ドラッグなし）なら自動攻撃のON/OFF切り替えとして扱われる |
| Space / マウス右クリック | パリィ（はじきかえす。自分・同僚に向かってくる弾を、周囲まとめてはじき返す。右クリックは左ドラッグで移動中でも機能する） |
| F / 画面内の「自動連射」ボタン | 自動攻撃のON/OFF切り替え（ボタンはONの間、色が変わってひと目で分かるようになっています） |
| P | 一時停止 / 再開 |
| 数字キー・Y/N など | 各種選択画面での選択（画面の案内に従ってください） |

移動用ジョイスティック・ポーズ／パリィ／連射／自動連射の各ボタンは、戦闘画面（実際にプレイ中の画面）以外では自動的に非表示になります（タイトル・エンディング・アドベンチャーパートなどの会話シーン中は誤操作防止のため隠れます）。

タイトル画面の操作説明には、上記のうち要点だけが次のように表示されます：
```
Space / 右クリック = パリィ（はじきかえす）
WASD・十字ボタン = 移動（マウスドラッグでも移動可能）　マウスポインタ = 向き　左クリック = アイテム取得・自動攻撃ON/OFF
```

### スマートフォン（タッチ）
- 画面外・左下の**移動ジョイスティック**：指を倒した方向へ移動。倒した方向にそのまま自分の向き（照準）も変わります。その真上に**自動連射ON/OFFボタン**があります
- 画面外・右下の**連射ボタン**：押している間、狙いを自動で近くの敵に定めながら攻撃（「スマホ用 自動照準」設定で挙動を切替可能）
- 連射ボタンの真上の**パリィボタン**：向かってくる弾をはじき返す
- メニュー画面の選択肢は、ボタンをタップするだけでOKです
- 画面を縦向き（ポートレート）にすると「横向きにしてください」という案内が表示されます。横向き（ランドスケープ）で遊んでください

## ゲームの始め方

1. `index.html` をブラウザで開く
2. スタート画面で「通常開始」か「3倍加速モード」を選ぶ（3倍速は時間の流れが速くなるモードです。※一度もノーマルエンドを経ていない最初のプレイでは選べません）
3. **自機の性別**（男性／女性）を選ぶ
4. **同僚のアイコン**を6種類の中から選ぶ、または「同僚なし」を選ぶ
5. ひとことメッセージのあと、ゲームが始まります

タイトル画面左上には「リセット」（全記録の初期化）・「記憶」（現在の引き継ぎ状況の確認、詳しくは[後述](#記憶画面について)）・「やめる」（ゲームを閉じる）の3つの小さなボタンがあります。「強化」「エンディングリスト」ボタンは、一度もノーマルエンドを経ていない最初のプレイ中は表示されません（詳しくは[初めてのプレイ（プロローグ）について](#初めてのプレイプロローグについて)を参照）。

## 画面の見方（HUD）

- 左上：選択したアイコンとパラメータをまとめた、コンパクトな**自分プロフィール区画**（幅130px、左に詰めて配置）。ポートレートの端に**「LV n」バッジ**が重なって表示され、その下に役職名が小さく表示されます
- その右：同じ幅・同じ高さに並ぶ**同僚プロフィール区画**（同僚なし・離脱時も状態を表示）
- 各プロフィールのイラスト下：それぞれの**SAN・寿命・脳疲労・残機（×N）**。自分側にはScore・Skill Lvl / EXPも表示。残機が0になると赤く点滅します
- プロフィール区画の下：**日ノルマ**の進捗と、完全オートモード・3倍加速・自動照準（スマホ用）の切り替えボタン（3つとも同じ大きさに揃えて縦に並びます）
- 右上：**DAY数・日付・時刻・曜日**（例：`DAY12 2026/07/11 (土) 16:00`。土日祝日は黄色で表示）。ラスボス戦の間はすべて「?」表示になります
- 画面中央上部：ゲーム内のできごとを知らせる一時メッセージ
- クイズ正解・スキルレベル上昇時：ゲームが一時停止し、確認通知をクリック／タップすると再開（昇進はゲームを止めず、その場でメッセージ表示のみ）
- 寿命が残り少ないほど、画面の端からひび割れ・暗転が進行する演出が入ります
- 自分・同僚のSANがいずれも20を切ると、画面全体が暗く赤みがかった不穏な空気になります（ラスボス出現の前兆）
- **一時停止画面（Pキー）**：自分・同僚の基本パラメータ（SAN・寿命・脳疲労・Score・Rank・関係性など）に加え、現在かかっているバフ・デバフ、習得済みの特殊スキル・役職スキルの一覧をまとめて確認できます

## ゲームの流れ

```
性別・同僚選択 → スタート画面 → 平日を働く（1日=8:00〜） → DAY表示でクリック/タップ待ち → 翌日へ
                                        │
                        「日ノルマ」（撃破数）を達成した瞬間、その日は即座に終業扱いになる
                        （定時報告・「大規模プロジェクト」が残っている間は、片付けるまで持ち越し）
                                        │
                        まだノルマ未達成のまま18時（dayEndHour）を迎えた場合
                                        │
                              強制的に残業（24時まで、選択の余地なし）
                                        │
                        ノルマ達成 or 残っていた定時報告・中ボスの解決 or 24時到達で終業へ
                                        │
                                 5日おきに「アドベンチャーパート」（同僚との会話イベント）
                                        │
                                週の最終稼働日（金曜、祝日ならその前日）は必ず休養日として処理
                                （同僚との関係性回復・体調回復などの休養イベントが自動発生。出勤の選択肢はない）
                                        │
                                クリック/タップで次の週（月曜日）へ
```

これを月の末日を迎えるまで繰り返します。月末まで到達すると「ゲームクリア」＝エンディングとなります（詳しくは[エンディング](#エンディング)を参照）。DAY7ごとの18時には「大規模プロジェクト」（中ボス）が、SANが自分・同僚とも20を切るとラスボスが割り込んでくることがあります。

**ただし、一度もノーマルエンドを経ていない最初のプレイだけは、上記と流れが大きく異なります。** 詳しくは次の章を参照してください。

### 仕事（敵）を片付ける
- 敵の正体は「問い合わせ対応」「障害対応」「インシデント対応」など、弱い順に10種類の仕事です。ランクが上がるほど、強い（＝厄介な）仕事も出現するようになります。
- 敵は**最大3体（1ウェーブ）**まで同時に出現し、**全員片付けるまで次のウェーブは出てきません**。
- 敵にはそれぞれ**納期**（3.5〜15秒のランダムな残り時間）があり、時間切れになると「爆発」してSANにダメージを受けます。**納期が短い敵ほど移動速度が速く**（最大2.2倍）、油断できません。
- 敵を倒すと**Score**・**経験値（EXP）**・**日ノルマの進捗**が増えます。

## 初めてのプレイ（プロローグ）について

**一度もノーマルエンドに到達したことがない状態**（＝このゲームを初めて遊ぶ時）は、いわば「チュートリアル」的な特別モードとして扱われます。

- **アドベンチャーパート（同僚との会話イベント）が一切発生しません。**
- 代わりに、実際に働いた日数（カフェイン摂取で倒れてスキップした日は除く。土日を挟んでも正しく数えられます）が**5日**に達した時点で、画面がゆっくり黒くフェードアウトし、そのまま強制的なボス戦イベント（下記）に突入します。
- 5日間の間、敵の出方が段階的に変化します。
  - **1日目**：固定敵（脅威）は出現しません。
  - **2日目**：固定敵が出始めます（画面内に最大2体まで）。
  - **3日目以降**：固定敵は最大3体まで同時に出現する可能性があります。
  - **4日目**：実際のランクによらず、高ランクの敵も出現し始めます。
  - **5日目**：実際のランクによらず最高ランクの敵まで出現可能になり、さらに敵の出方が「ウェーブ制」ではなく、ゲーム内1時間に5体相当のランダムな間隔で画面外から個別に襲来する形に変わります。
- 「完全オートモード」「3倍加速」「スマホ用自動照準」は使用できません（ボタン自体が表示されません）。
- タイトル画面の「強化」（夢の記憶ポイントでの強化）・「エンディングリスト」ボタンも表示されません。

この特別な5日間の最後に突入するボス戦（下記「[ラスボス・中ボスについて](#ラスボス中ボスについて)」の「ノーマルルート終了時の負けイベント戦闘」と同じもの）では、**発射口は決して破壊できません**。同僚が力尽きる演出のあと、エンディング画面が表示されます。

ここで到達した関係性の値は「前回プレイの関係性」として次の周回に引き継がれます。**一度でもノーマルエンド（後述）に到達すると、2周目以降は通常どおりアドベンチャーパートが発生するようになり**、関係性次第では「夢ルート」やその先の「目覚めエンド」（事実上のTRUE END）を目指せるようになります。

## 各種システムの詳細

### 残機システム
- 自分・同僚それぞれに、初期**3回の「残機」**があります。
- SANまたは寿命が0になっても、残機が残っていれば即座にゲームオーバーにはなりません。代わりに**5秒間気絶**し（その間、半透明で明滅し、周囲を星が回ります）、その後SAN・寿命がそれぞれ最大値の**50%**まで回復して復活します。復活直後の**3秒間は無敵**（誤射も受け付けません）になります。
- 残機が尽きた状態でもう一度SANまたは寿命が0になると、通常どおりゲームオーバー（バッドエンド）になります。
- 残機はHUDに「残機: ×N」として表示され、0になると赤く点滅します。
- かなり稀に、輝くエフェクトの付いた超レアアイテム「**残機+1**」が画面上部から降ってきます（他のアイテムと同様、放置すると一定時間で消滅）。取得した側（自分または同僚）の残機がそのまま1増えます。同僚はこのアイテムを最優先で積極的に取りに行きます。

### 時間帯ライティング
- 朝は薄い暖色を重ねて明るく表示し、夕方へ近づくほど画面全体が連続的に暗くなります。
- 暗い時間帯でも、自分と同僚の周囲は円形にぼんやり照らされます。離れた敵ほど見つけにくくなります。

### 定時報告
- **3日ごとの16時**に、画面内のランダムな位置へ固定ターゲット「定時報告」（📊）が出現します。
- 通常の仕事より大幅にHPが高く、その場から移動しません。同僚も通常の仕事より優先して攻撃します。撃破するとScoreを獲得します。
- 接触ダメージはありませんが、固定された障害物として扱われ、自分も同僚も通り抜けられません。
- 18時までに倒せないと消滅し、現在の**Scoreが半分**になります。

### 昼食・チョコレート・ファイヤーウォール
- 11時になると昼食が近いことを知らせる予告が表示されます。毎日12時に、4個の食べ物が約0.55秒間隔で一つずつランダムな位置へ出現します。
- 15時になると残った食べ物が点滅し始め、約1.8秒後に消滅して未取得数の判定が行われます。
- 一品取るごとにSAN +2、寿命 +0.5、脳疲労 -3の小回復があります。出現順どおりに全品取ると、追加でSAN +10、寿命 +15、脳疲労 -50のフルボーナスに加え、ゲーム内1時間、移動速度120%・発射間隔75%・被ダメージ50%になる強化効果を獲得します。順番を一度でも間違えるとボーナスは半減し、強化効果も付きません。
- 終業までの取得数が半分以下なら「ちゃんと食事を取らなかった」と判定され、寿命が5減ります。
- チョコレート（🍫、画面にランダム出現）は脳疲労を回復します。
- 低確率で出現する希少アイテム「**ファイヤーウォール**」を取得すると、誤射・接触ダメージを一定回数無効化するバリアが張られます。
- さらに稀にしか出現しない超レアアイテム「**残機+1**」については、[残機システム](#残機システム)を参照してください。
- **完全オートモード中**は、自機がこれらのアイテムに直接触れるだけで自動的に取得されます（クリックは不要）。また、自機は自発的に**昼食・チョコレート・ファイヤーウォール・残機+1**を優先して取りに行きます（栄養ドリンク・コーヒーは自発的には取りに行きませんが、通りがかって触れれば自動取得されます）。

### 脳疲労・コーヒー・栄養ドリンク
- 発射とは無関係に、時間の経過だけでじわじわ蓄積します（通常時：ゲーム内1時間あたり6、残業中：9、オート連射中はさらに+12）。最大値に達すると一時的に操作不能（居眠り状態）になり、SANダメージに加えて寿命も2〜3減ります。
- 同僚は常にオート連射中と同じ扱いになりますが、蓄積速度には0.6倍の緩和がかかっています。
- 画面端に固定されたコーヒーメーカー・冷蔵庫から、**コーヒー**（SAN+10・寿命-2。効果中は脳疲労が上限に達さずstunしない代わり、効果が切れた瞬間まだ頭打ちなら通常の3倍の時間stunする）と**栄養ドリンク**（効果は強いが切れると反動あり）を随時補充できます。同僚もこれらを飲みます。
- コーヒー・栄養ドリンクを飲みすぎたり、夕方以降に飲んだりすると、回復量減少などのペナルティが入ります。

### SAN値（精神力）
- 敵との接触、納期切れの爆発、脳疲労の限界到達、日ノルマ未達成時のペナルティ、休日イベントの一部などでダメージを受けます。
- **0になり残機も尽きるとゲームオーバー**（バッドエンド：発狂パターン）。

### 寿命（健康）
- SANとは別の、じわじわとしか減らない・じわじわとしか自覚できないパラメータです。
  - SANダメージを受けるたびに、その**15%ぶん**が寿命にも波及します
  - 脳疲労が80%を超えた状態、またはSANが20%を下回った状態が**4秒以上続く**と、その後は1秒ごとに少しずつ削れていきます
- **0になり残機も尽きるとゲームオーバー**（バッドエンド：力尽きるパターン）。SANを回復させても、蓄積した消耗（寿命）は元に戻らないのがポイントです。

### 日ノルマ・残業
- 1日ごとに、**撃破数**がその日のノルマ値に達すればクリアです（ランクが上がるほど、また稼働日数が進むほどノルマ値も少しずつ上がります）。
- **一度でもノーマルエンドを経た後**は、ノルマを達成した瞬間、その日は即座に終業扱いになります（＝早くノルマを達成するほど、早く一日が終わります）。ただし定時報告や「大規模プロジェクト」がまだ残っている場合は、それらを片付けるまで終業が持ち越されます。
  - **一度もノーマルエンドを経ていない最初のプレイ（チュートリアル期間）中**は、この即終業は行われず、従来どおりノルマ達成後は「その日の残りが易しい仕事しか出てこなくなる」だけです。
- **18時（終業予定時刻）までにノルマを達成できなかった場合、選択の余地なく強制的に残業に入ります**（定時報告や中ボスが未処理の場合も同様）。残業中はSANが徐々に減っていきます。
- 残業中にノルマを達成する（または残っていた定時報告・中ボスを片付ける）と、その場で即座に終業となります。達成できないまま24時（`maxOvertimeHour`）を迎えても、それ以上の追加ペナルティなくそのまま終業します。
- 週の最終稼働日（金曜、祝日ならその前日）は、ノルマ達成状況に関わらず**必ず休養日**として処理されます。出勤するかどうかの選択肢はなく、同僚との関係性回復や体調回復などの休養イベントが自動的に発生します。
- 平日10時・15時にランダムでクイズが出題されることがあります（**1日1回まで**）。正解するとゲームが一時停止し、確認通知をクリック／タップすると再開します。

### ランク・役職スキル
- 「昇進」を選ぶ場面はなく、**Scoreに応じてランク（役職名）が自動的・段階的に上がっていきます**（週末を待たず、その場で判定されます）。スコアが複数ランク分の条件を満たしていれば飛び級もあり得ます。最終ランク（Rank7）への到達条件は特に厳しく設定されています。
- ランクが上がると、そのランクに紐づく**役職スキル**（身につけた開発手法）を自動的にすべて習得します。選択の余地はなく、恒久的な効果として積み重なっていきます。
- 自分のランクが上がると、**同僚も自動的に強化されます**：ランク2・4・6で発射間隔が短縮、ランク3で移動速度1.5倍、ランク5でマルチタスクAのような追加弾を獲得します。

| 1 | 新人 | 構造化プログラミング（弾のダメージ+10%） |
| 2 | PG | オブジェクト指向（EXP獲得+20%） |

### 敵の強さの変化
- 基本攻撃力は20、基本発射間隔は175ms（かなり速射寄りの設定）です。これに合わせて、敵のHP（残り工数）も、最弱の敵でも2〜4発は必要になる水準まで引き上げてあります。
- 敵のHPと、接触・爆発によるSANダメージ（攻撃力）は、**ゲーム内の経過日数に応じてどんどん強くなっていきます**（1日ごとに約4.5%）。同じ種類の仕事でも、後半になるほど手強くなります。
- **固定敵（下記）の弾ダメージ・トラップダメージも、同じ日数成長の対象**です。以前はHPだけが日数とともに育ち攻撃力は据え置きだったため、終盤ほど無害になっていましたが、現在は攻撃力も同じペースで育つよう調整されています。
- 敵ごとに設定された納期が短いほど、その敵は速く動きます（最大で通常の2.2倍）。

### スキルレベルと経験値
- 敵を倒すと経験値（EXP）が入り、貯まるとスキルレベルが上がります。
- レベルアップに必要な経験値は、**レベルが上がるほど増えていきます**（後半は上がりにくくなる調整済み）。
- スキルレベルが5上がるごとに、下記の**特殊スキル**を1つ選んで習得（またはレベルアップ）できる権利が貯まります。ただし選択画面はその場では開かず、**1日の終わりにまとめて**（黒フェードアウトのあと、翌日の「DAY〇〇」表示の前に）選ぶ形になります。

### フルオートモード
- 移動・攻撃・回避をすべて自動で行うモードです。移動の優先度は「同僚やボスの弾を避ける」＞「敵を避ける」＞「昼食・チョコ・ファイヤーウォールを取りに行く」＞「同僚との距離を保つ」の順で判断します。
- アイテムに直接触れると自動で取得します。近くまで来た援護弾（下記）も可能なら自動でパリィします。
- 一度もノーマルエンドを経ていない最初のプレイでは使用できません。

## 同僚について（パリィ・関係性・再会シーン）

- ゲーム開始時にアイコンを選ぶと、自分に付き従う仲間が登場します（「同僚なし」も選択可）。
- 自分との距離を広めに取り、追従はゆっくり行います。多くの時間は画面内のランダムな位置へ自発的に徘徊し、近くの敵に自動で攻撃します。撃破した分はプレイヤーのScore・日ノルマ・EXPにそのまま加算されます。
- 自分と同僚の弾は互いにも当たり、誤射されるとSANと寿命が減ります。「チームワーク」を習得すると被害を軽減できます。
- 同僚との関係性は0（最悪）～100（良好）の内部パラメータとして管理されます。自分の弾を当てるたびに悪化し、一定以下になると同僚がときどき自分を狙います。アドベンチャーパートでの選択次第で改善・悪化します。悪化して0に近づくほど、同僚アイコンの円形フレームが連続的に赤くなります。
- 自分と同じように**脳疲労・SAN・寿命・残機（3回）**を持ち、敵との接触でSANが減り、悪い状態が続くと寿命も減ります。
- **SANまたは寿命が0になり、残機も尽きると、同僚は力尽きて以後二度と登場しません**。同僚を一度でも失うと、その周回で目覚めエンド（TRUE END）の条件を満たせなくなります。

### パリィ（弾のはじき返し）
- Space／マウス右クリック（スマホはパリィボタン）で、自分・同僚に向かってくる弾を周囲まとめてはじき返せます。複数同時パリィも可能です。右クリックは、左クリックで自機をドラッグ移動している最中でも機能します。
- 同僚も自動で、被弾しそうな時に一定確率（初期30%、夢の記憶ポイントで強化可能）でパリィし、「パリィ！」「効かないよ！」などの吹き出しを表示します。
- パリィで反射した弾は速度が1.5倍になり、発射元（ラスボス・中ボスの発射口）に向かって飛んでいきます。
- 特殊スキル「**ライトセーバー**」を習得すると、パリィの効果範囲が1.2倍、パリィの直接攻撃（ワイプ範囲内の敵を直接なぎ払う）ダメージが3倍になり、専用の光る刃エフェクトが表示されます。さらに上位の「**闇を切り裂く剣**」では効果範囲3倍・直接攻撃ダメージ10倍まで強化され、ノーマルルート終了時の負けイベント戦闘に限り、本来決して破壊できない発射口も3回の命中で破壊できるようになります（この2つは同時に習得できません）。
- どちらのスキルも、パリィの直接攻撃が中ボス・ラスボスの発射口にまで届くようになります（通常の敵だけでなく、発射口へも直接ダメージを与えられます）。

### 再会シーン
- 前回プレイと同じ自機の性別・同僚を選んでゲームを始めると、前回の関係性・最期の状況に応じた再会シーン（セリフ・アイコンの色味変化）が挿入されます。

## アドベンチャーパートと夢ルート

**一度でもノーマルエンドに到達したことがある**周回では、実際に働いた日数が5日に達するたびに「アドベンチャーパート」（同僚との会話イベント）が発生します。

- **1回目（ADV1）**：AかBの2択。**2番目の選択肢（B）を選ぶと、その時点の関係性がそのまま半分になる**（1番目の選択肢は関係性+10）大きな分かれ道です。
- **2回目（ADV2）**：ADV1の選択に応じて、C/D（Aルート）またはE/F（Bルート）の2択。ここでも**2番目の選択肢（D／F）を選ぶと関係性が半分になります**（1番目は+10）。
- **3回目（ADV3）**：ここまでの選択と関係性次第で、通常の分岐に加えて「**夢ルート**」（前世の記憶に触れるような特別な会話）に入れることがあります。夢の記憶ポイントで「目覚め」を購入していれば、条件によらず必ず夢ルートに入れます。
- **4回目以降**：選択肢はなく、その時点の関係性に応じて自動的にエンディングルートが決まります。
- 2つ以上の選択肢が表示される場面では、**表示直後の1秒間はクリック・タップを受け付けません**（誤操作防止）。

### ADV3の後
- **夢ルートを完走した場合**：翌日の通常業務には入らず、不穏な「24:00」の時計表示（クリックするまで、表示が高速でランダムな時刻へ切り替わり続けます。クリックすると赤く染まりながら爪痕・取り消し線が浮かび上がり、フェードアウト）を経て、専用の見た目を持つ特別なラスボス戦に直行します。これを撃破し、同僚が生きていれば「**目覚めエンド**」（事実上のTRUE END）に到達します。
- **夢ルートに入らなかった／完走しなかった場合**：「ノーマルルート終了時の負けイベント戦闘」（下記）に入ります。

## ラスボス・中ボスについて

### ラスボス
- 自分・同僚のSANがいずれも20を切ると、窓の外から名状しがたい巨大な存在が現れます。出現中は時間が止まり、通常の敵は現れず、ラスボスとだけ戦うことになります。
- 本体には複数の発射口があり、そこから自分・同僚どちらかを狙って弾が飛んできます。本体そのものへの接触でもダメージを受けます。
- 発射口はそれぞれ耐久力を持ち、通常攻撃・パリィどちらでも破壊できます。段階を経るごとに発射口が増減・変化していきます。第2段階「シャドウ」では、発射口の1つが自分の、もう1つが同僚の半透明な姿に化けており、**自分の弾で自分そっくりの発射口を撃つと90%の確率でパリィされて**しまいます。
- すべての発射口を破壊しきると、本体が振動しながらゆっくり後退・フェードアウトして消え、背景が元のオフィスに戻ったあと画面が白く（または、同僚を失っている場合は黒く）フェードし、エンディングへ至ります。
- 中ボス（「大規模プロジェクト」）が出現中は、ラスボスは発生しません。

### ノーマルルート終了時の負けイベント戦闘
- ADV3で夢ルートに入らなかった場合（および、一度もノーマルエンドを経ていない最初のプレイで5日目を終えた場合）に突入する、専用の見た目を持つ強制イベント戦です。
- 画面が静止→振動しながら暗転→「？？？？」という名の存在が降臨、という演出のあと戦闘が始まります。突入時の自分・同僚の位置は、その時点の関係性が**良好なら直前の相対距離のまま**、**普通／悪いなら画面中央から少し左右に離して**再配置されます。
- **一度もノーマルエンドを経ていない場合、発射口は決して破壊できません。** 一度でもノーマルエンドを経ている場合は、発射口は1つにつき1000回の被弾で破壊可能になり、万が一すべて破壊してしまうと、通常のラスボス撃破と同じ演出を経て目覚めエンドにつながります。
- 戦闘開始からランダムな時間が経つと、同僚が力尽きる演出（全体がスローモーションになり、同僚が点滅しながら消える）が入り、その後「{同僚}を助けないと…」という一文とともにエンディング画面へ至ります。

### 中ボス（「大規模プロジェクト」）
- DAY7ごとの18時に、窓の上を動き回る「大規模プロジェクト」が出現します。出現すると自動的に残業モードに入り、24時までに倒せなければ24時で時刻が停止し、倒すまで継続します（時刻表示には鉛筆で取り消し線を引いたようなエフェクトが重なります）。
- 発射口は「フェーズ」と呼ばれ、システム開発の工程（①企画・②要件定義・③基本設計・④詳細設計・⑤開発・⑥テスト・⑦リリース・運用保守）になぞらえた7つを持ちます。それぞれ本体の上をゆっくりランダムに動き回りますが、**番号順にしか破壊できません**（現在の番号以外は鍵がかかったように無効化されています）。
- 今対応中のフェーズの番号・名称と、その工程の内容（現実の説明文）が画面にフェードイン表示され、破壊するまで表示され続けます。破壊すると「◯. ○○完了！」と表示されてフェードアウトし、次のフェーズへ進みます。破壊した発射口はその場で消滅します。
- 全7フェーズを破壊し終えると、動作はラスボスとほぼ同様（振動・フェードアウトして撃破）です。撃破すると通常の敵より多めのScoreが手に入ります。
- フェーズ1つあたりの耐久力はDAYが進むごとに上がります（DAY7を基準に、DAY14で2倍、DAY21で3倍、DAY28以降で5倍）。
- 倒した翌日は通常どおり、残業なしで始まります。

### 援護弾
- ラスボス・中ボスがなかなか倒せない時、救済措置としてゲーム内3時間ごとに一定確率で、自機から見て最も遠い画面端から自機へ向かって援護弾が飛んできます。
- パリィすると、今対応すべき部位へ飛んでいき一撃で破壊します。何もしなければそのまま通り過ぎて消えます。完全オートモード中は、範囲内に入ると可能な限り自動でパリィされます。

## 固定敵（IT用語モチーフ）

- 平日13時に判定され、**60%の確率（週3回程度）**で1体だけ出現する、移動しない特殊な敵です。名称はIT・セキュリティ用語から取られ、現実の攻撃内容にちなんだ攻撃パターン・被弾時の悪影響を持ちます。
- 定時報告・ラスボス・中ボスとは同時に出現しません。倒せないまま終業を迎えると、ペナルティなしで見逃す形になります。
- 通常の弾・パリィで撃破可能です（一部はパリィで打ち返した弾を本体に向けて反射させられます）。撃破するとScoreを獲得し、その用語の**現実の説明文**が画面上部にフェードイン→3秒表示→フェードアウトします。
- 攻撃パターンは大きく5種類：**弾を発射する**（DoS・ブルートフォース・ゼロデイなど）、**弾を介さず直接効果を及ぼす**（SQLインジェクション・ランサムウェアなど）、**偽アイテムの罠を置く**（フィッシング・DNSスプーフィングなど）、**自機に見せかけて同僚を誤射させる**（なりすまし・中間者攻撃）、**雑魚を追加召喚する**（ボットネット）。
- 被弾時の効果例：発射間隔延長、移動速度低下、操作反転、Score浸食、一時的な攻撃不能、脳疲労急増、疲労回復停止＋継続SANダメージ、視界不良、移動乗っ取り、同僚の一時的な行動停止、関係性ダメージ、一定確率で回避（キーロガー）、撃破後の遅延不意打ち（バックドア設置）など。
- 一度もノーマルエンドを経ていない最初のプレイでは、1日目は固定敵が出現せず、2日目は最大2体、3日目以降は最大3体まで段階的に解禁されます。

| 攻撃名 | 攻撃パターン | 主な被弾効果 |
|---|---|---|
| DoS攻撃 | 3連続の弾を発射 | 発射間隔が一時的に延びる |
| DDoS攻撃 | 5連続の弾＋雑魚を召喚 | 移動速度が低下する |
| XSS | 単発の弾 | 操作（移動キー）が一時的に反転する |

| CSRF | 単発の弾 | 一時的に攻撃できなくなる |
| フィッシング | 偽の回復アイテムの罠を設置 | 脳疲労が急増する |

## 夢の記憶ポイント（周回強化）

- ゲームオーバー・クリア時に獲得したScoreの一部が「夢の記憶ポイント」に変換され、`localStorage` に永続的に保存されます。役職（ランク）・役職スキル・Scoreも、終了時点の状態がそのまま次周に引き継がれます。
- タイトル画面の「強化」から、初期スキルレベル・初期SAN／寿命上限・初期脳疲労上限・初期スコア・初期攻撃力・初期移動速度・初期バリア回数・同僚との初期関係性・日ノルマ緩和・同僚のオートパリィ確率などを、ポイントを消費して強化できます。同じ画面から、特殊スキルを事前にレベルアップしておける専用ページにも入れます。
- 「思い直す」ボタンで、費やしたポイントを全額払い戻し、レベルを0に戻して振り分け直せます。
- 一部の強化は1レベルのみ購入可能な特殊効果です。例：
  - `DreamCatcher`：SAN上限を25固定にしてラスボスに遭遇しやすくする
  - `希望`：自分・同僚それぞれ、SANが0にならなくなる
  - `UnDead`：自分・同僚それぞれ、**残機を使い切った状態（残機×0）に限り**、寿命が0にならなくなる（残機が残っている間は、通常どおり残機を消費して気絶・復活する）
  - `固い絆`：同僚との関係性が下がらなくなる
  - `ワーカホリック`：脳疲労が一切蓄積しなくなる
  - `目覚め`：第3回のアドベンチャーパートで、これまでの選択・関係性によらず必ず夢ルートに入る
  - `β版設定`：SAN・寿命が0にならず脳疲労も常に0のまま、攻撃力が50倍になる検証用の特殊スキル。中ボス・ラスボス戦では最低5発で撃破できるようになる
- タイトル画面の「エンディングリスト」ボタンから、これまでに到達したエンディングの一覧を確認できます（未到達のものは内容が伏せられます）。
- これらの「強化」「エンディングリスト」ボタンは、一度もノーマルエンドに到達していない最初のプレイ中は表示されません。

## 「記憶」画面について

タイトル画面左上の「記憶」ボタンから開ける、現在の引き継ぎ状況を一覧できる画面です。

- **目覚めエンドへの到達状況**：ノーマルエンドの経験の有無（アドベンチャーパートが発生するかどうか）、「目覚め」強化の習得状況、前回プレイの関係性・エンディング種別、真エンド（ラスボス撃破）到達済みかどうか
- 前回プレイの自機・同僚の組み合わせを、アイコンで確認できます

## エンディング

月末（クリア）・ゲームオーバー・ラスボス撃破時に、いずれかのエンディングへ至ります。

独立した「TRUE END」は存在せず、**目覚めエンド（ラスボスを撃破し、同僚が生存している状態で終える）が事実上のTRUE END**です。夢ルートを経てラスボスに挑むのが主な到達手段です。

| エンディング | 到達条件 |
|---|---|
| **目覚めエンド** 👁️ | ラスボスを撃破し、同僚が生存している状態で終えた場合（事実上のTRUE END） |
| **再び悪夢エンド** 🖤 | ラスボスを撃破したが、同僚を失っている場合 |
| **END（良好／普通／悪い）** 🌤️🏁🌧️ | ラスボスに挑まないまま月末に到達した場合。同僚との関係性で3段階に分かれる |
| **END（心）** 🌀 | SAN値が0になった場合 |
| **END（寿命）** ⚰️ | 寿命が0になった場合 |
| **END（同僚）** 💔 | 同僚の誤射でとどめを刺された場合 |
| **END（孤独）** 🗂️ | 同僚がいないまま、第3回のアドベンチャーパートに入るべき日を迎えた場合 |

通常のエンディング画面には「…という、夢…？」（最初からやり直し。夢の記憶ポイント等は引き継ぎ）・「終了する」（タブを閉じようと試みます）のボタンがあります。到達済みのエンディングは、タイトル画面の「エンディングリスト」からいつでも確認できます。

**END（心）・END（寿命）・END（孤独）**の3つは、画面が急に切り替わらないよう演出が加えられています。END（心）・END（寿命）は、力尽きる演出（静止→振動・明滅→点滅しながら消える→黒フェードアウト）のあと、エンディング画面自体が黒から浮かび上がるようにフェードインします。END（孤独）は、それまでの画面が一度黒くフェードアウトしたあと、同じくエンディング画面がフェードインします。

## 目覚めエンド専用タイトル画面

目覚めエンド（ラスボス撃破・同僚生存）に到達すると、通常のタイトル画面へ戻る代わりに、専用の明朝体調タイトル画面（"Wakin' UnDead"）が表示されます。3つのボタンがあります。

- **エンディングリスト**：専用デザインの一覧画面が開きます。
- **就活を始める**：タイトルがゆっくり白へ消えたあと、クリックで自機・同僚の組み合わせに対応するエンディング画像がフェードインし、もう一度クリックすると画面が白くフェードアウトしてゲームが終了します。
- **寝る**：同僚との関係値・前回の組み合わせだけをリセットし（役職・Score・記憶ポイントは維持）、黒フェードアウト→不穏な背景画像がだんだん拡大しながらフェードイン→拡大を続けたまま暗転、を経て、通常のタイトル画面へ戻ります（戻った瞬間、画面が黒からゆっくりフェードインします）。

## 現状の制約・仮実装について

- 自機・同僚・背景（朝〜夜）は画像素材が用意済みですが、**中ボス「大規模プロジェクト」の見た目はまだ矩形のプレースホルダー**、**固定敵（IT用語モチーフ）は絵文字アイコンのみ**です（正式な画像は追加予定）。
- **サウンド・音楽は未実装です**（`sounds/` フォルダは空です）。
- スコアをサーバーへ送信する処理（`sendScore`）は `http://localhost:8080/score` 宛て決め打ちです。受け取るサーバーが無い場合はコンソールにエラーが出るだけで、ゲーム進行には影響しません。
- 数値バランス（ノルマ・ランク条件・成長率・敵の耐久力など）は、遊びながらの調整を重ねた初期チューニングであり、今後も見直しが必要になる可能性があります。

## ファイル構成

```
index.html   … ページの骨組み、タッチ操作UI（移動ジョイスティック・連射・パリィボタン）・回転案内オーバーレイ
style.css    … レイアウト、レスポンシブ対応、モバイル用ボタンの見た目
main.js      … ゲームロジック全体（1ファイルにまとまっています）
adventureScenes.js … アドベンチャーパートのシナリオデータ・台詞
images/      … 自機・同僚・背景・ラスボス・エンディングなどのグラフィック素材
sounds/      … 将来、効果音・BGMを置くための空フォルダ
```

`main.js` は上から順に、夢の記憶ポイント・エンディングリスト・固定敵（IT用語モチーフ）・敵の生成・弾とスコア・脳疲労/SAN/寿命システム・日付とカレンダー・日ノルマ・ランク/役職スキル・特殊スキル・入力処理（キーボード/マウス/タッチ）・同僚・パリィ・アドベンチャーパート・ラスボス／中ボス・各種エンディング演出・描画（`draw()`関数）という構成になっています。コメントで区切られているので、`// =====` を目印に探すと見つけやすいです。
